# Unemployment Analysis with Python

## Project Overview
This project analyzes unemployment data in India using Python. It explores unemployment rates across regions, compares rural and urban areas, and studies the impact of the COVID-19 period on unemployment.

## Objectives
- Analyze unemployment rate data.
- Clean and preprocess the dataset.
- Explore unemployment trends using Python.
- Compare unemployment before and during the COVID-19 period.
- Visualize unemployment patterns by region and area.
- Identify useful insights from the data.

## Dataset
- Dataset: Unemployment in India
- Source: Kaggle
- Period: May 2019 to June 2020
- Data includes region, unemployment rate, estimated employment, labour participation rate, and area type.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Analysis Performed
1. Data loading
2. Data cleaning
3. Missing value handling
4. Exploratory data analysis
5. Monthly unemployment trend visualization
6. Regional unemployment comparison
7. Rural vs Urban analysis
8. COVID-19 period comparison

## Key Findings
- Average unemployment rate was approximately 11.79%.
- Average unemployment before the COVID-19 period was approximately 9.51%.
- Average unemployment during the COVID-19 period was approximately 17.77%.
- Unemployment rates increased substantially during April and May 2020.
- Urban unemployment was higher than rural unemployment in this dataset.

## Conclusion
This project demonstrates how Python can be used for data cleaning, exploratory analysis, and visualization of economic data. The analysis highlights the increase in unemployment during the COVID-19 period and differences across regions and rural/urban areas.

The findings can help understand employment trends and may support further research into economic and social policies.
